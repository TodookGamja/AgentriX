# Backlog

## CLI 질문/선택 화면을 앱 UI로 가져오기

배경: CLI가 작업 중 사람에게 질문하면(선택지, 여러 질문 탭) 터미널 화면에 그려진다.
앱에서는 입력창에 포커스가 있어 방향키/Shift+방향키가 CLI로 가지 않아 질문을 열어 보거나 고를 수 없었다.

### 완료: 1단계 — 키 전달
- 입력창이 비어 있으면 ←↑↓→, Shift+방향키, Tab, Shift+Tab, Esc를 터미널로 그대로 전달 (`TerminalPane.tsx` `handleKeyDown`)
- 터미널 하단에 ← ↑ ↓ → Tab Esc 버튼 줄 추가
- 메시지 기록 넘기기는 Ctrl+↑/↓로 이동

### 보류: 3단계 — Claude Code 구조화 질문 수신 (먼저 조사)
- 목표: 화면을 추측하지 않고 정확한 질문/선택지를 받는다.
- 조사할 것: Claude Code 훅(예: 도구 사용 전/알림 이벤트)과 비대화형 출력 모드(stream-json)에서 질문(AskUserQuestion 등)이 구조화된 데이터로 오는지.
- 되면: 훅이 질문을 `.ai-agents/` 아래 파일로 남기고 앱이 읽어 카드로 표시, 선택 결과를 키 입력으로 되돌려 보낸다.
- 안 되면 2단계로 대체.

### 보류: 2단계 — 화면 출력 파싱으로 질문 감지
- 앱이 이미 받는 PTY 출력에서 `❯ 1. …` 같은 선택 목록 패턴을 읽어 앱 UI 카드로 표시.
- 카드 클릭 → 선택지까지 ↑/↓를 보내고 Enter 전송 (1단계의 키 전달 재사용).
- CLI마다 화면 모양이 달라 Claude Code부터 만들고 Codex, OpenCode 등으로 확장. CLI 업데이트로 깨질 수 있어 패턴을 CLI별 파일로 분리하고 테스트 샘플 화면을 남긴다.
- 주의: 선택지가 화면 밖으로 스크롤되거나 여러 질문 탭인 경우, 잘못 감지했을 때 엉뚱한 키가 들어가는 경우를 막아야 한다.

### 순서
1단계(완료) → 도구 완성도를 높인 뒤 3단계 조사 → 결과에 따라 2단계 방식 결정.
