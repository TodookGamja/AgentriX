## 한국어
- **🧠 실제 컨텍스트 토큰 측정**: Claude Code·Codex·Antigravity·OpenCode는 CLI 로그에서 실제 컨텍스트 토큰을 읽어 토큰 최적화에 사용 (로그가 없는 CLI는 기존 추정치 사용)
- **🗜️ 자동 /compact 수정**: 임계치 도달 시 /compact가 실행되지 않고 바로 새 세션으로 넘어가던 문제 수정, 응답이 끝난 뒤 압축 실행
- **📜 스크롤 시 토큰 증가 수정**: 터미널을 위아래로 스크롤만 해도 추정 토큰이 올라가던 문제 수정
- **🔁 세션 인수인계 시 지시 이어받기**: 새 세션으로 넘어갈 때 이전에 받은 지시를 인수인계 파일에 담아 작업을 끝까지 이어서 수행 (앱 재시작 후에도 유지)
- **🛑 블랙보드 중복 보고 방지**: 모든 작업이 완료되면 PM에게 완료 알림을 다시 보내지 않음
- **🔐 권한 설정 통합**: 프로젝트 패널·분할 슬롯·자동 인수인계 등 모든 실행 경로가 같은 CLI 권한 설정을 사용
- **👤 프로필 설정 창 분리**: 프로필 편집을 별도 창으로 정리

## English
- **🧠 Real context token measurement**: Claude Code, Codex, Antigravity, and OpenCode now read actual context tokens from CLI logs for token optimization (CLIs without logs keep using the estimate)
- **🗜️ Auto /compact fix**: Fixed /compact being skipped and jumping straight to a new session at the threshold; compaction now runs once the response finishes
- **📜 Scroll no longer inflates tokens**: Scrolling the terminal up and down no longer increases the estimated token count
- **🔁 Instructions carried over on session handoff**: When relaying to a new session, previously received instructions are included in the handoff file so work continues to completion (persists across app restarts)
- **🛑 No duplicate blackboard reports**: The PM is no longer re-notified once every task is done
- **🔐 Unified permission settings**: All launch paths (project panel, split slots, auto handoff) use the same CLI permission settings
- **👤 Separate profile settings window**: Profile editing moved into its own window
