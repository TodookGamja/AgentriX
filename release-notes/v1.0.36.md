## 한국어

- **🔐 MCP 서버 신뢰 질문 자동 승인**: 앱에 등록된 프로젝트에서 Claude 세션을 시작하기 전에 프로젝트 `.claude/settings.local.json`에 MCP 서버 승인을 미리 기록합니다. 새 MCP 서버가 생겨도 세션이 신뢰 질문에서 멈추지 않습니다. 등록하지 않은 폴더는 건드리지 않습니다.
- **🛡️ 폴더 신뢰는 등록 프로젝트에만**: Claude 폴더 신뢰(`~/.claude.json`)도 앱에 등록된 프로젝트에서만 기록합니다. 이미 신뢰된 폴더는 파일을 다시 쓰지 않고, 써야 할 때는 잠금·임시 파일 교체·직전 재읽기 병합으로 다른 설정이 깨지거나 사라지지 않게 저장합니다.
- **📬 중간 메일 뒤 완료 보고가 빠지던 문제 수정**: 팀원이 작업 중 '중간 결과'·'결정 부탁' 같은 메일을 보낸 뒤 작업표를 ✅로 바꾸면 PM에게 [완료 보고]가 가지 않아 다음 작업이 멈추던 문제를 고쳤습니다.
- **⏭️ '전달 결과 미확인' 항목이 대기열을 막던 문제 수정**: 이미 끝난 작업의 메일이 '전달 결과 미확인'으로 대기열 맨 앞에 남아 새 작업 배정이 계속 '앞 전달 대기'에 머물던 문제를 고쳤습니다. 작업표에서 완료·통합·취소된 작업의 항목은 미확인이어도 정리되고, 미확인 항목은 다시 보내지 않되 뒤 항목의 전달을 막지 않습니다.

- **⚠️ 알려진 제약**: 마켓플레이스로 설치한 플러그인을 업데이트한 뒤 뜨는 훅 신뢰 질문과, 로그인된 Codex 세션의 신뢰 질문은 격리 환경에서 로그인할 수 없어 확인하지 못했습니다. 이 질문들은 아직 자동 승인하지 않습니다.
- **⚠️ 알려진 제약**: Claude가 `~/.claude.json`을 같은 순간에 교체하면 나중에 저장한 쪽이 앞의 변경을 덮을 수 있습니다. 이미 신뢰된 폴더는 쓰지 않도록 해 가능성을 줄였습니다.
- **⚠️ 알려진 제약**: 완료 보고 판정은 메일 제목의 단어로 중간 메일을 가려냅니다. 목록에 없는 표현의 중간 메일 뒤에는 완료 보고가 여전히 빠질 수 있습니다.

## English

- **🔐 MCP server trust prompts approved automatically**: Before a Claude session starts in a project registered in the app, MCP server approval is written to the project's `.claude/settings.local.json`, so new MCP servers no longer stop the session at a trust prompt. Unregistered folders are left untouched.
- **🛡️ Folder trust only for registered projects**: Claude folder trust in `~/.claude.json` is now written only for projects registered in the app. Already-trusted folders are not rewritten, and writes use a lock, temp-file replace and re-read merge so other settings are not corrupted or lost.
- **📬 Fixed missing completion reports after progress mail**: When a teammate mailed an interim update (e.g. progress, decision request) and then marked the task ✅, the PM no longer misses the [completion report] that kicks off the next task.
- **⏭️ "Delivery unconfirmed" items no longer block the queue**: Mail for an already-finished task could sit at the head of a teammate's queue as "delivery unconfirmed" and hold new assignments at "waiting for earlier delivery" forever. Items for tasks that are done, merged or cancelled on the board are now cleared even when unconfirmed, and unconfirmed items are never re-sent but no longer block the items behind them.

- **⚠️ Known limitation**: Hook trust prompts after updating a marketplace-installed plugin, and trust prompts in signed-in Codex sessions, could not be verified because the isolated test environment cannot sign in. These prompts are not auto-approved yet.
- **⚠️ Known limitation**: If Claude replaces `~/.claude.json` at the exact same moment, the later write can overwrite the earlier change. Skipping writes for already-trusted folders keeps this rare.
- **⚠️ Known limitation**: Interim mail is recognized by words in the subject. Interim mail phrased differently can still suppress the completion report.
