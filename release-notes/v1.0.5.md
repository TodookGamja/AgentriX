## 한국어
- **🪙 출근 때 역할 턴 제거**: 에이전트가 출근할 때 역할 지침을 채팅으로 보내지 않습니다. Claude는 시스템 지시(`--append-system-prompt-file`)로 받고, 이를 지원하지 않는 CLI(Codex·OpenCode 등)는 첫 지시 앞에 역할을 한 번만 붙입니다. 할 일이 없는데 역할만 읽고 응답하느라 토큰을 쓰던 턴이 없어집니다
- **📉 릴레이 토큰 절감**: 인수인계 파일을 최근 지시 5개 위주로 3,000자 이하로 줄였습니다. 앱이 자동으로 넣은 브리핑·팀 메일은 지시 이력에 남기지 않습니다. 자동 릴레이 뒤 새 세션은 바로 작업시키지 않고, 다음 지시가 올 때 안내 1줄만 붙입니다
- **⌨️ 긴 배정문 Enter 누락 수정**: 여러 줄이나 긴 배정문이 Codex 등의 입력창에 들어가기만 하고 제출되지 않던 문제를 고쳤습니다. 붙여넣기 모드를 켠 CLI에는 붙여넣기 범위를 표시해 보내고, 반응이 없으면 Enter를 한 번 더 보냅니다
- **🧱 배정 쌓임 방지**: 앞 배정이 제출되지 않았으면 다음 배정을 같은 입력창에 쓰지 않습니다. 15초가 지나도 시작되지 않으면 작업보드 카드에 '입력창에 멈춤'으로 표시합니다. 오래 작업 중인 팀원은 멈춤으로 표시하지 않습니다

### 알려진 제한
- 사용 중 콘솔 창이 잠깐 떴다 사라지는 현상의 원인을 아직 확정하지 못했습니다. 앱이 직접 실행하는 프로세스에는 모두 창 숨김 플래그가 있음을 테스트로 확인했고, 추적은 계속합니다
- 터미널 화면에 직접 키를 쳐서 보낸 첫 입력에는 역할 안내가 붙지 않습니다(아래 입력창으로 보내면 붙습니다)
- 키 보관함은 아직 단순 난독화이며 Windows 자격 증명 관리자로 옮길 예정입니다(V104_SEC1)
- 앱 명령 권한이 메인 창에 일괄 열려 있어 범위를 좁힐 예정입니다(V104_SEC2)
- CSP 이미지 출처에 `http:`가 남아 있어 제거할 예정입니다(V104_SEC5)

## English
- **🪙 No more role-briefing turn on clock-in**: Agents no longer receive their role as a chat message when they start. Claude gets it as a system instruction (`--append-system-prompt-file`); CLIs without that option (Codex, OpenCode, etc.) get the role prepended once to their first instruction. The turn agents spent reading and acknowledging the role with nothing to do is gone
- **📉 Cheaper relays**: The handoff file now stays under 3,000 characters, focused on the last 5 instructions. Briefings and team mail injected by the app are no longer recorded as instructions. After an auto relay the new session is not put to work right away; a one-line pointer is added to its next instruction
- **⌨️ Fixed long assignments not being submitted**: Long or multi-line assignments could land in the input box of Codex and others without being submitted. CLIs that enable paste mode now receive the text as an explicit paste, and Enter is resent once if nothing happens
- **🧱 No more stacked assignments**: A new assignment is not written into an input box whose previous assignment was never submitted. If work has not started after 15 seconds, the task-board card shows "stuck in input box". Teammates who are busy on long work are not flagged

### Known limitations
- The cause of a console window briefly flashing during use is not confirmed yet. Tests verify that every process the app launches directly uses the hide-window flag; investigation continues
- The role notice is not attached to a first input typed directly into the terminal (it is attached when sent from the input box below)
- The key vault still uses simple obfuscation; moving it to Windows Credential Manager is planned (V104_SEC1)
- App command permissions are exposed to the main window as a whole and will be narrowed (V104_SEC2)
- The CSP image source still allows `http:` and will be tightened (V104_SEC5)
