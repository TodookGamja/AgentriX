## 한국어

- **AI CLI 전체 권한 설정**: 전체 권한 모드에서 Claude, Codex, Grok, Cursor, Antigravity의 샌드박스를 해제하고, 팀 에이전트에도 선택한 권한 설정을 적용합니다. OpenCode는 모든 권한을 자동 승인하며, 나머지 CLI의 샌드박스 제어 여부는 도구와 실행 환경에 따릅니다.
- **Headroom OFF 적용**: 전역 설정을 끄면 새 CLI 세션에서 Headroom 래퍼를 사용하지 않습니다. 이미 실행 중인 세션에는 다시 시작한 뒤 적용됩니다.
- **작업 완료 후 토큰 최적화**: Claude, Codex, OpenCode의 완료 기록을 확인한 후 최적화를 시도합니다. 완료 여부 또는 세션을 구분할 수 없으면 자동 실행을 보류합니다.
- **터미널 작업 유지**: 세션별 채팅 입력과 첨부파일을 화면 전환 시 유지하고, 탭을 드래그해 순서를 바꾸며, 릴레이 세션을 기존 위치에 배치합니다.
- **Cursor 사용량 표시**: 사이드바 전환에 Cursor를 추가하고 월간 전체 사용량으로 표시합니다. 실제 월간 쿼터 연동은 아직 지원하지 않아 확인 불가로 표시합니다.
- **알림 표시**: 긴 백업 경로가 알림창 밖으로 넘치지 않도록 수정했습니다.

## English

- **AI CLI full access**: Full access mode disables the Claude, Codex, Grok, Cursor and Antigravity sandboxes; team agents use the selected permission settings. OpenCode automatically approves permissions; sandbox control for other CLIs depends on the tool and environment.
- **Headroom OFF**: Disabling Headroom globally prevents new CLI sessions from using the wrapper. Existing sessions must be restarted.
- **Optimization after completion**: Automatic optimization waits for completion records from Claude, Codex, or OpenCode. It is deferred when completion or session identity cannot be confirmed.
- **Terminal continuity**: Drafts and attachments survive view changes, tabs can be reordered by dragging, and relay sessions appear in the original position.
- **Cursor usage display**: Cursor is available in the sidebar and its quota is labeled monthly. Actual monthly quota integration is not yet available and is shown as unavailable.
- **Notifications**: Long backup paths now wrap inside the notification.
