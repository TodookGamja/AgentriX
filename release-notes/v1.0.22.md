## 한국어
- **📨 전달 복제·유실 방지**: 배정·메일·완료 보고를 에이전트별 한 줄 대기열로 순서대로 한 건씩 전달합니다. 제출이 확인되지 않은 건은 지우지 않고 "확인 안 됨"으로 남기며, 같은 내용을 자동으로 다시 보내지 않습니다.
- **🔓 "앞 전달 처리 중" 고착 해결**: 전달 중 응답이 없으면 15초 뒤 잠금을 풀고 다음 건으로 넘어갑니다. 늦게 끝난 시도는 내용을 쓰지 않습니다.
- **📤 지금 보내기 오판정 수정**: 실제로 보냈는데 확인만 실패한 항목은 "보냈지만 확인 못 함"으로 표시하고 재전송 버튼을 막습니다.
- **📋 작업 보드 5단계**: 승인 대기 / 대기 / 진행 중 / 완료 / 반려로 나눠, 아직 전달 안 된 작업은 사유와 함께 "대기"에 표시합니다.
- **✨ 작업 중 탭 표시 복구**: 출력 없이 오래 생각하는 턴도 작업 중으로 판단해 탭이 다시 반짝입니다.
- **🧭 Codex 이어하기**: 세션을 이어서 열 때 역할 지침이 중복으로 들어가지 않습니다.
- **🪵 전달 단계 로그**: 전달 단계와 소요 시간을 `delivery.log`에 남깁니다(메시지 본문은 기록하지 않음).

## English
- **📨 No duplicated or lost deliveries**: Assignments, mail and completion reports go through a per-agent queue, one at a time and in order. Unconfirmed submissions are kept as "unconfirmed" and never resent automatically.
- **🔓 Stuck "previous delivery in progress" fixed**: A delivery that gets no response releases its lock after 15 seconds and the next item proceeds. Late attempts no longer write their content.
- **📤 Send-now false failure fixed**: Items that were sent but could not be confirmed show "sent, not confirmed" and cannot be resent.
- **📋 Five-column task board**: Awaiting approval / Waiting / In progress / Done / Rejected. Tasks not yet delivered appear under Waiting with the reason.
- **✨ Busy tab pulse restored**: Turns that think for a long time without output still count as busy, so the tab pulses again.
- **🧭 Codex resume**: Resuming a Codex session no longer injects the role instructions twice.
- **🪵 Delivery step log**: Delivery steps and timings are written to `delivery.log` (message content is never logged).
