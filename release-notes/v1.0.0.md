## 한국어
- **🧩 플러그인 새 버전 알림**: 설치된 Claude 플러그인에 새 버전이 올라오면 카드에 배지가 뜨고, 버튼 한 번으로 업데이트합니다
- **🔎 플러그인·스킬·MCP 검색**: 이름·설명으로 검색하고 카드/리스트 보기를 고를 수 있습니다. 목록에는 이름·설명·적용 CLI만 보이고 상세는 클릭해서 확인합니다
- **✅ 작업 보드(수동 승인)**: PM이 올린 작업을 승인·반려할 수 있는 탭을 추가했습니다. 반려 사유는 PM에게 전달됩니다
- **🤝 팀 소통 안정화**: PM이 체크리스트로 작업표를 써도, 팀원이 outbox에 마크다운 보고서를 써도 인식합니다
- **⚡ Headroom 설정 반영**: 전역 Headroom이 꺼져 있으면 팀원도 래퍼 없이 실행하고, 래퍼 토글이 에이전트 모델을 지우던 문제를 수정했습니다
- **🪟 콘솔창 깜빡임 완화**: 시작할 때마다 CLI 모델 목록을 조회하지 않고 24시간 캐시합니다
## English
- **🧩 Plugin update alerts**: installed Claude plugins with a newer version show a badge and can be updated in one click
- **🔎 Plugin/skill/MCP search**: search by name or description, switch between card and list views, and open details on click
- **✅ Task board (manual approval)**: new tab to approve or reject tasks the PM posts; rejection reasons are sent to the PM
- **🤝 More robust team messaging**: checklist-style task boards and markdown reports in the outbox are now recognized
- **⚡ Headroom setting respected**: agents no longer launch with the wrapper when global Headroom is off, and toggling the wrapper no longer clears an agent's model
- **🪟 Fewer console flashes**: CLI model lists are cached for 24 hours instead of queried on every start
