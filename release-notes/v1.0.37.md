## 한국어

- **🧹 없는 세션을 '이미 실행 중'으로 막던 문제 수정**: 탭을 닫았거나 프로세스가 끝난 세션이 목록에 남아 팀원을 다시 실행할 수 없던 문제를 고쳤습니다. 끝난 세션은 목록에서 바로 정리됩니다.
- **🔀 이어 열 대화가 겹치면 새 대화로 시작**: 팀원이 이어 열려는 이전 대화를 다른 탭이 이미 쓰고 있으면, 오류 대신 새 대화로 시작합니다. 다른 팀원의 대화를 가로채지 않습니다.
- **👉 이미 실행 중이면 그 탭으로 이동**: 실제로 실행 중인 팀원을 다시 실행하면 오류 대신 그 팀원의 탭을 열어 보여 줍니다. 숨겨진 탭이나 다른 분할 칸에 있어도 찾아 엽니다. 탭을 찾지 못하면 앱 안 창에서 '새 대화로 시작'을 고를 수 있습니다.
- **⏩ 앞 항목이 없는데 '앞 전달 대기'로 멈추던 문제 수정**: 이미 사라진 전달 예약이 남아 팀원 대기열이 '앞 전달 대기'로 멈추던 문제를 고쳤습니다. 주인 없는 예약은 30초 뒤 정리되고 다음 항목이 자동으로 전달됩니다.
- **⚠️ 알려진 제약**: 이전 버전에서 겪은 '이미 실행 중' 오류가 어느 원인이었는지는 기록이 없어 확인할 수 없습니다. 두 원인을 모두 고쳤고, 앞으로는 원인이 로그에 남습니다.

## English

- **🧹 Fixed "already running" for sessions that no longer exist**: Sessions whose tab was closed or whose process exited could linger and block relaunching that teammate. Ended sessions are now removed right away.
- **🔀 Start fresh when the conversation to resume is taken**: If another tab is already using the conversation a teammate would resume, the teammate now starts a new conversation instead of failing, and never takes over another teammate's conversation.
- **👉 Jump to the running session**: Launching a teammate that is genuinely running now opens and focuses its tab instead of showing an error, even if the tab is hidden or in another split pane. If the tab can't be found, an in-app dialog offers "Start new conversation".
- **⏩ Fixed queues stuck on "waiting for earlier delivery" with nothing ahead**: A leftover delivery reservation with no matching queue item could freeze a teammate's queue. Orphaned reservations are now cleared after 30 seconds and the next item is delivered automatically.
- **⚠️ Known limitation**: Which cause triggered "already running" errors in earlier versions can't be determined because they weren't logged. Both causes are fixed and are now logged.
