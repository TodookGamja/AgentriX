## English
- **🖱️ Drag projects between groups** in the left sidebar
- **⚡ Faster startup**: log scanning no longer holds the DB lock, so projects and usage load sooner and appear as they arrive
- **🧭 Installed AIs only**: team recommendations no longer include CLIs that aren't installed
- **👥 Team building AI and model choice**: pick which AIs to use and get a recommended model per agent
- **🧩 Model list fixes**: added OpenCode and Cursor model lists; empty results are no longer cached
- **🎲 Varied team recommendations + custom names and roles**: no more identical results, with a request box, re-recommend, and editable names and roles
- **💬 Teammates talk by name**: team messages and blackboard task tables accept teammate names
- **🛠️ Token tool install detection**: detects uv and Headroom and installs them with one click
- **⌨️ Keys reach CLI prompts**: with an empty input box, arrows, Shift+arrows, Tab and Esc go to the terminal, plus arrow buttons (message history is now Ctrl+Up/Down)
