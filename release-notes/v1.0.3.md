## 한국어
- **📋 작업보드 패널**: 헤더 버튼으로 BLACKBOARD 작업을 4열 칸반(승인 대기/진행 중/완료/반려)으로 확인합니다. 완료 열은 최근 5개만 보이고 나머지는 펼쳐 볼 수 있습니다
- **💡 작업 중 표시**: 출력 중인 터미널은 CLI 색 테두리가 맥동하고 헤더에 "작업 중" 스피너가 표시됩니다
- **📨 팀 메일·배정 전달 안정화**: 유휴 세션에만 순서대로 전달하고, 끊긴 전달은 재시도하며, 중복 전달을 막았습니다
- **🤝 PM 협업 규칙 주입**: PM을 개별 실행해도 작업표·팀 메시지 규칙이 자동으로 주입됩니다
- **🖥️ 터미널 수정**: 다른 화면에 다녀오면 터미널이 깨지던 문제, codex가 찾기 모드로 바뀌고 cursor에 `[1;1R`이 쌓이던 문제를 수정했습니다
- **🛡️ 보안 강화**: CSP 적용, 업데이트 주소·서명 검증, PTY 명령 주입 차단, 오류 복구 화면(ErrorBoundary) 추가

### 알려진 제한
- 앱 내 업데이트는 서명 공개키가 설정되기 전까지 비활성화되어 있습니다. 새 버전은 GitHub Releases에서 직접 받아 주세요
- API 키는 아직 단순 난독화로 저장되며, Windows 자격 증명 관리자 이전은 v1.0.4에서 진행합니다
- 앱 내부 명령 권한 범위 축소, 키 원문 전달·임의 파일 읽기 차단은 v1.0.4에서 진행합니다
- CSP 정책상 Ollama는 로컬 주소(localhost)만 연결되며 원격 Ollama 서버는 차단됩니다

## English
- **📋 Task Board Panel**: A header button shows BLACKBOARD tasks as a 4-column kanban (pending / in progress / done / rejected). The done column shows the latest 5 with an expand toggle
- **💡 Busy indicator**: Terminals producing output glow in their CLI color with a "working" spinner in the header
- **📨 Reliable team mail & task delivery**: Delivered in order only to idle sessions, stalled deliveries are retried, duplicates are dropped
- **🤝 PM collaboration rules**: Running the PM on its own now injects the task-board and team-message rules automatically
- **🖥️ Terminal fixes**: Fixed terminals breaking after switching screens, codex dropping into Find mode, and stray `[1;1R` in cursor
- **🛡️ Security hardening**: CSP, update URL and signature checks, PTY command-injection blocking, and an error recovery screen (ErrorBoundary)

### Known limitations
- In-app update stays disabled until the signing public key is configured. Please download new versions from GitHub Releases
- API keys are still stored with simple obfuscation; moving them to Windows Credential Manager is planned for v1.0.4
- Narrowing app command permissions and blocking raw key exposure / arbitrary file reads are planned for v1.0.4
- Due to CSP, Ollama connects only to local addresses (localhost); remote Ollama servers are blocked
