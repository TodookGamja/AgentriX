- **📦 더 작은 배포 파일**: 실행 파일이 약 16MB에서 11MB로 줄었고, 포터블 ZIP 대신 `AgentriX.exe` 하나로 배포합니다
- **💡 작업 중 표시**: 출력 중인 터미널은 CLI 색 테두리가 맥동하고 헤더에 "작업 중" 스피너가 표시됩니다
- **📨 팀 메일·배정 전달 안정화**: 유휴 세션에만 순서대로 전달하고, 끊긴 전달은 재시도하며, 중복 전달을 막았습니다
- **🤝 PM 협업 규칙 주입**: PM을 개별 실행해도 작업표·팀 메시지 규칙이 자동으로 주입됩니다
- **🖥️ 터미널 수정**: 다른 화면에 다녀오면 터미널이 깨지던 문제, codex가 찾기 모드로 바뀌고 cursor에 `[1;1R`이 쌓이던 문제를 수정했습니다
- **🛡️ 보안 강화**: 앱 안 업데이트 서명 검증, API 키 원문 노출 차단, 파일 읽기 경로 제한, CSP 적용, 업데이트 주소 검증, PTY 명령 주입 차단, 오류 복구 화면(ErrorBoundary) 추가

### 알려진 제한
- v1.0.2 이하에서는 앱 안 업데이트로 v1.0.3을 받을 수 있지만, 이후 버전부터는 서명(`AgentriX.exe.sig`)이 확인된 파일만 설치됩니다
- 사용자 폴더 밖(예: 다른 드라이브)의 이미지는 첨부할 수 없습니다
- Deep AI API 키는 더 이상 브라우저 저장소에 평문으로 남지 않습니다. 다만 키 보관함은 아직 단순 난독화로 저장되며, Windows 자격 증명 관리자 이전은 v1.0.4에서 진행합니다
- 앱 내부 명령 권한 범위 축소는 v1.0.4에서 진행합니다
- CSP 정책상 Ollama는 로컬 주소(localhost)만 연결되며 원격 Ollama 서버는 차단됩니다

## English
- **📋 Task Board Panel**: A header button shows BLACKBOARD tasks as a 4-column kanban (pending / in progress / done / rejected). The done column shows the latest 5 with an expand toggle
- **📦 Smaller downloads**: the executable shrank from about 16MB to 11MB, and the portable ZIP is replaced by a single `AgentriX.exe`
- **💡 Busy indicator**: Terminals producing output glow in their CLI color with a "working" spinner in the header
- **📨 Reliable team mail & task delivery**: Delivered in order only to idle sessions, stalled deliveries are retried, duplicates are dropped
- **🤝 PM collaboration rules**: Running the PM on its own now injects the task-board and team-message rules automatically
- **🖥️ Terminal fixes**: Fixed terminals breaking after switching screens, codex dropping into Find mode, and stray `[1;1R` in cursor
- **🛡️ Security hardening**: signed in-app updates, no raw API key exposure, restricted file reads, CSP, update URL checks, PTY command-injection blocking, and an error recovery screen (ErrorBoundary)

### Known limitations
- From v1.0.3 on, in-app updates install only files whose signature (`AgentriX.exe.sig`) verifies
- Images outside your user profile folder (e.g. other drives) cannot be attached
- Deep AI API keys are no longer kept in plain text in browser storage. The key vault still uses simple obfuscation; moving them to Windows Credential Manager is planned for v1.0.4
- Narrowing app command permissions is planned for v1.0.4
- Due to CSP, Ollama connects only to local addresses (localhost); remote Ollama servers are blocked
