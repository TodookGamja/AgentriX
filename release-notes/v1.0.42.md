## 한국어

- 팀원 채팅의 **전송**은 콘솔에 직접 전달하고, **대기에 넣기**는 대기열을 사용합니다. 진행 중인 쓰기는 순서대로 처리합니다.
- 작업보드에 실제 터미널 대기열을 표시하고 선행 작업이 없는 대기 작업을 시작할 수 있습니다.
- Claude가 종료된 뒤 남은 셸 때문에 재시작이 막히는 경로를 수정하고 종료 코드를 표시합니다.
- Codex 유휴 화면 판정과 터미널 마우스 입력 전달, 탭 전환 시 출력 처리를 개선했습니다.

알려진 제한: 기존 Claude 프로세스가 처음 종료된 원인은 확인되지 않았으며, 화면 표시와 스크롤 수정은 설치된 앱에서 추가 검증이 필요합니다.

## English

- **Send** delivers team chat to the console; **Queue** explicitly queues it. Writes remain serialized.
- The work board displays the live terminal queue and can start waiting tasks with no pending prerequisites.
- Claude shells no longer keep an exited CLI session alive, and the wrapper reports the exit code.
- Improved Codex idle detection, terminal mouse input, and output handling during tab changes.

Known limitations: the original cause of the previous Claude exits is unknown; display and scrolling fixes require verification in the installed app.
