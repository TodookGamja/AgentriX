## 한국어
- **⏩ /compact 직후 자동 전송 복구**: 새 Claude Code가 남기는 평문 `/compact`·`/clear`·`/model` 기록을 사용자 지시로 오인해 "응답 중"으로 멈추던 문제를 고쳤습니다. 명령이 끝나면 대기열이 바로 전달됩니다.
- **🧭 결과 메일을 받은 PM이 멈추지 않음**: PM에게 가는 메일 꼬리말이 "결과를 받으면 답장하지 말고 BLACKBOARD를 확인해 다음 작업을 배정하거나 최종 보고하세요"로 바뀌었습니다. 메일 형식과 무관하게 PM이 다음 단계로 진행합니다. 팀원 메일은 그대로입니다.
- **🧹 처리 끝난 메일 재전송 방지**: 이미 처리된 메일이 대기열에 남아 다시 들어가던 문제를 고쳤습니다. 처리된 메일은 대기열에서 자동 정리되고, 아직 처리 안 된 메일은 유지됩니다.

## English
- **⏩ Auto-delivery right after /compact**: Plain `/compact`, `/clear` and `/model` entries written by newer Claude Code were mistaken for a user turn, leaving the session "busy". Queued items now go out as soon as the command finishes.
- **🧭 PM keeps going after result mails**: Mail delivered to the PM now ends with "don't reply to results; check BLACKBOARD and assign the next task or give the final report", so the PM moves on regardless of mail format. Teammate mail is unchanged.
- **🧹 No re-delivery of handled mail**: Mail that was already processed no longer lingers in the queue and gets sent again. Handled mail is cleared automatically; unprocessed mail is kept.
