## 한국어
- **🖱️ Cursor 턴 감지**: Cursor 화면의 "ctrl+c to stop" 표시로 작업 중/종료를 판단합니다. 작업이 끝나면 대기 중인 배정·메일이 10초 안에 자동으로 들어가고, 작업 중에는 들어가지 않습니다.
- **✅ Cursor 제출 확인 오판 수정**: 실제로 제출됐는데 "제출 확인 실패"가 뜨던 문제를 고쳤습니다. Working 표시나 `[Pasted text #N]` 기록이 보이면 제출된 것으로 처리합니다.
- **📋 Codex 긴 붙여넣기 제출**: 긴 내용이 `[Pasted Content]` 칩으로만 남고 제출되지 않던 문제를 고쳤습니다. 본문은 한 번만 보내고, 칩이 남아 있으면 Enter만 최대 2회 다시 보냅니다.
- **✨ Cursor 작업 중 탭 표시**: Cursor 탭도 실제 작업 중일 때만 반짝입니다.

## English
- **🖱️ Cursor turn detection**: Busy/idle is read from Cursor's on-screen "ctrl+c to stop" indicator. Queued assignments and mail are delivered within 10 seconds after a turn ends, and never while it is running.
- **✅ Cursor submit confirmation fixed**: Submissions that went through no longer show "submit confirmation failed". A Working indicator or a `[Pasted text #N]` entry counts as submitted.
- **📋 Codex long paste submission**: Long input no longer gets stuck as a `[Pasted Content]` chip. The body is sent once, and only Enter is retried (up to 2 times) while the chip remains.
- **✨ Cursor busy tab pulse**: Cursor tabs pulse only while actually working.
