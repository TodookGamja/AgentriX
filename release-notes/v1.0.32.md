## 한국어
- **🪟 확인창·알림을 앱 화면 안에서 표시**: 작업 취소·앱 초기화·입력창 글 확인·오류 알림이 더 이상 "tauri.localhost의 메시지" 브라우저 창으로 뜨지 않고 앱 안 모달로 뜹니다. Esc·바깥 클릭은 취소, 되돌릴 수 없는 동작은 '취소'에 기본 포커스가 있어 Enter 실수로 실행되지 않으며, 창이 열린 동안 Alt+숫자·Alt+S·F11·줌 단축키가 막힙니다.
- **🛰️ agy 팀원 역할 지침 무한 반복 수정**: 전달이 시간 초과·중단으로 끝나도 이미 입력창에 들어간 역할 지침을 '안 보냄'으로 되돌리지 않아, 지침만 끝없이 다시 들어가던 문제가 사라졌습니다.

- **🗑️ 작업판 취소 저장 보호**: 취소 저장 직전에 작업표를 다시 읽어, 그 사이 다른 팀원이 바꾼 내용을 덮어쓰지 않습니다(최대 3회 재시도).

## English
- **🪟 Confirmations and alerts now appear inside the app**: Cancelling a task, resetting the app, sending over a half-typed input, and error alerts no longer pop up as a "tauri.localhost says" browser dialog; they use an in-app modal. Esc or clicking outside cancels, destructive actions focus "Cancel" by default so a stray Enter does nothing, and Alt+number, Alt+S, F11 and zoom shortcuts are blocked while the dialog is open.
- **🛰️ Fixed endless role-instruction repeats for agy teammates**: When a delivery ended by timeout or interruption, a role instruction already typed into the input box was marked as unsent and re-sent forever. It now stays sent.
- **⏯️ Fixed stalled delivery queues**: A Claude session sitting at an empty prompt for 30+ seconds, or a Codex turn that ended as interrupted, is now treated as idle so queued items go out. Busy or tool-running sessions are never interrupted, and unconfirmed deliveries are not counted as finished.
- **💡 Idle teammate tabs no longer glow**: One-off redraw output and unfinished old turns no longer make idle tabs pulse. The tab tooltip explains what the glow means.
- **🗑️ Safer task-board cancel**: The task table is re-read right before a cancel is saved, so concurrent edits by other teammates are preserved (up to 3 retries).
