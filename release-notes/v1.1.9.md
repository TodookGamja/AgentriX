## 한국어
- **🛠️ Headroom 설치 감지 수정**: Headroom 본체만 설치되고 프록시 구성요소(fastapi 등)가 없는 환경을 "설치됨"으로 잘못 표시하던 문제 수정. 누락 시 "프록시 구성요소 누락"으로 표시하고 설치 버튼으로 함께 설치
## English
- **🛠️ Headroom install detection fix**: environments with Headroom installed but missing the proxy components (fastapi etc.) were reported as installed. They are now flagged as "proxy components missing" and the install button installs them
