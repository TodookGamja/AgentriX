## 한국어
- **🖱️ Cursor 작업 중 전달 차단**: 도구 실행·명령 승인 대기 중에는 메일·배정이 끼어들지 않습니다. 작업 표시가 5초 이상 사라지고 출력이 3초 이상 멈춘 뒤에만 전달하며, 보내기 직전에 한 번 더 확인합니다.
- **💠 작업 중 탭 강조**: 작업 중인 탭에 청록 테두리가 표시됩니다. Windows 애니메이션 효과를 끈 PC에서도 보입니다.
- **📬 대기열 멈춤 해결**: `/compact`·`/clear`·`/model` 뒤에도 자동 전달이 이어지고, 맨 앞 항목 때문에 뒤 항목이 모두 멈추던 문제를 고쳤습니다. 이미 완료된 배정은 대기열에서 자동으로 정리됩니다.
- **🔁 중복 알림 정리**: 같은 작업의 완료 보고와 결과 메일이 함께 대기하면 메일 1건만 전달합니다.
- **🔐 API 키 보호 강화**: 저장된 API 키를 Windows DPAPI로 암호화합니다. 기존 키는 앱 시작 시 손실 없이 자동 이전됩니다.
- **🛡️ 보안 정책 강화**: 이미지 로드에서 암호화되지 않은 `http:` 주소를 차단하고, 앱 기능 호출을 실제 사용하는 69개로 제한했습니다.

## English
- **🖱️ No delivery during Cursor work**: Mail and assignments no longer interrupt tool runs or command approval prompts. Delivery waits until the busy indicator has been gone for 5s and output has been quiet for 3s, and is re-checked right before sending.
- **💠 Busy tab highlight**: Busy tabs show a cyan ring, visible even when Windows animation effects are turned off.
- **📬 Queue stalls fixed**: Auto-delivery continues after `/compact`, `/clear` and `/model`, and a stuck first item no longer blocks everything behind it. Assignments already completed are cleared from the queue automatically.
- **🔁 Duplicate notices merged**: When a completion report and a result mail for the same task are both waiting, only the mail is delivered.
- **🔐 Stronger API key protection**: Stored API keys are encrypted with Windows DPAPI. Existing keys are migrated automatically on startup without loss.
- **🛡️ Tighter security policy**: Unencrypted `http:` image sources are blocked, and app commands are limited to the 69 actually used.
